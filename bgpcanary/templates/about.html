How to update

Updates are installed on the server (the web app deliberately has no system privileges). Run:

sudo bgpcanary-update

It backs up the database and settings first, downloads the latest release, installs it (your configuration, data, users and certificate are kept), and checks that the service comes back. If anything goes wrong, sudo bgpcanary-update --rollback returns to the previous version and database. sudo bgpcanary-update --check only reports whether a newer version exists.
