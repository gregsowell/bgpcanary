Using it

Send it in the Authorization: Bearer … header of requests to:

/api/v1/status
each prefix's visibility, state and neighbours, and how many events are open
/api/v1/events
the events, with the Events page's filters
/api/v1/events/ID
one event and the alerts sent for it; /report after it for its text report
/api/v1/neighbours/ASN
what a neighbouring network is to you, and the events about it
/api/v1/me
who the token is
