Tips
  • Microsoft 365: smtp.office365.com, port 587, STARTTLS. The mailbox needs Authenticated SMTP enabled (M365 admin center, then the user's Mail settings, then Manage email apps). Many tenants turn it off by default.
  • Google Workspace: smtp.gmail.com, port 587, STARTTLS, with an app password rather than the account password.
  • Internal relay: often the simplest option. Allow the VM's IP on the relay, use port 25 with security "None", and leave the username and password empty.

Add a webhook

How to get a Slack webhook URL
  1. Open api.slack.com/apps and choose Create New App, then From scratch. Name it (e.g. "bgpcanary") and pick your workspace.
  2. Open Incoming Webhooks, switch it On, then click Add New Webhook to Workspace.
  3. Pick the channel, click Allow, then copy the URL into the form above and click Test.
How to get a Microsoft Teams webhook URL
  1. In Teams, open the channel, click ⋯ (More options) next to its name and choose Workflows.
  2. Pick the template Send webhook alerts to a channel, name it (e.g. "bgpcanary"), and click Next.
  3. Check the team and channel, click Add workflow, then copy the URL it shows.
  4. Add it above with the format Microsoft Teams and click Test. Alerts arrive as cards posted by the Workflows app.

Older "Incoming Webhook" connector URLs (…webhook.office.com…) also work with this format until Microsoft retires them.

The generic JSON format

The JSON format posts {phase, state, subject, text, link, event{…}}. Use it for PagerDuty-style receivers, automation tools, or your own scripts.
