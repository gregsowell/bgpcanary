What this adds

BGP data tells you whether networks have a route to you. RIPE Atlas probes (small devices in thousands of networks) test whether traffic actually arrives, and how fast. With it on, bgpcanary:

  • pings your probe target from a set of probes around the world, plus probes inside each of your upstreams' transit providers, and charts latency and packet loss grouped by the carrier the traffic arrives through
  • runs traceroutes from the same probes, drawn as a radial map that shows where paths stop
  • fires a one-off traceroute burst from many networks when an outage opens and when it clears

It's optional: everything else works without it. Measurements cost Atlas credits. You earn them by hosting a probe (a hardware probe, or the free software probe on any Linux box, ~21,600 credits a day) or get them from another Atlas user. Create an API key under My Atlas › API keys with the permissions Create a new user defined measurement, Stop a user defined measurement and See your credit balance.

Tests the key typed above, or the saved one, with one real ping from one probe (about 6 credits). Saves nothing.

Carrier probes are picked from inside the networks your upstreams buy transit from or peer with (the left-hand side of the dashboard tree), so you can see e.g. "everything entering through carrier X is losing packets". Changing probes or intervals replaces the running baseline measurements. If a measurement would push the day's committed credits over the cap, it isn't started.

Earn credits: host a probe

Atlas measurements are paid for with credits, and hosting a probe is how you earn them: a connected probe earns about 21,600 credits a day, more than the default settings here spend (~9,600). Credits go to the Atlas account the probe is registered to, so the probe can run anywhere: this server, another Linux box, a Raspberry Pi, or a hardware probe. It needs a stable connection and little else (a few MB of RAM and roughly 5-10 kbit/s).

Somewhere else

  • Another Linux machine (Debian 11-13, Raspberry Pi OS 12-13 on arm64, Rocky/RHEL/Oracle 8-10): follow the install steps in RIPE's software probe README, then register its key the same way.
  • A hardware probe: RIPE ships small probes for free; apply here. Plug it into any network with DHCP.
  • An anchor (a larger, dedicated server) earns more and is also a measurement target; see anchors.
  • Credits from someone else: any Atlas user can transfer credits to your account (My Atlas › Credits).

Probes in your own network also make good vantage points, but measurements toward your space are most useful from other networks, which is what bgpcanary picks. Credits start accruing once the probe has been connected for a while; a new account may wait up to a day.
