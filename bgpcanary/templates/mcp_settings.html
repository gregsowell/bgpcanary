Connect an assistant

Create a token under Settings › API tokens, then give the assistant the address and the token as a header:

Claude Code

claude mcp add --transport http bgpcanary {{ base }}/mcp --header "Authorization: Bearer bgpc_…"

Cursor, VS Code, Windsurf and other clients with a JSON config:

{
  "mcpServers": {
    "bgpcanary": {
      "url": "{{ base }}/mcp",
      "headers": { "Authorization": "Bearer bgpc_…" }
    }
  }
}

Claude Desktop needs a bridge, since it only starts local servers: mcp-remote (needs Node.js).

{
  "mcpServers": {
    "bgpcanary": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ base }}/mcp", "--header", "Authorization:${AUTH}"],
      "env": { "AUTH": "Bearer bgpc_…" }
    }
  }
}
